# Changelog
## DFC
### 3.1.6
- 允许在内置地图组件**DFC初始化器**中设置分队模式决定方式*SelectionModeDecideWay*（字符串类型，有效值“Manual”、“Random”、“ManualThenRandom”、“Vote”），为空时回退为Mod中的配置。
- 内置地图组件**新增派系**添加回调 *onPlayerParticipate*，在玩家参与到阵营时调用，传入参数为客户端。
### 3.1.5
- Mod设置内可以修改分队模式决定方式（手动、随机、先手动再30s后随机、投票），需要管理员权限。
- 内置地图组件**新建派系**允许改写重生相关功能：
    - 属性**OverrideStartRespawningMessageChunk**，返回一个lua函数，调用于重生开始倒计时，接收的参数有派系id、派系名称、重生等待时间，返回值为发送给玩家的消息文本，文本为空（nil，而非""）时将不发送任何消息。该属性未设置时，默认发送“xx阵营yy秒后重生……”。
    - 属性**GetRespawnLimitPerTimeChunk**，返回一个lua函数，用于设置本批次重生时的最大人数（按阵亡时间排序），接收的参数有派系id、派系死亡人数、派系总人数，返回值为此次可重生的限定最大人数，为nil时所有人重生，为0时无人重生。
    - 属性**OverrideRespawnedMessage**，返回一个lua函数，重生时调用，接收的参数有派系id、派系名称、重生的玩家id列表，返回值为发送给玩家的消息文本，文本为空（nil，而非""）时将不发送任何消息。该属性未设置时，默认发送“xx阵营已重生！”。
- 单人模式
    - 调试命令的入口从聊天框改到控制台，现在按下tab能自动补全了，输入“!dfc”查看所有命令。
    - 强化调试效果，*!assignjob*能够直接生成角色。
    - 新增调试命令 *!spawncharacter*，可指定派系、职业、出装，从而一步生成角色。
- 派系、职业、出装在分配时，相应的回调*onJoined*, *onAssigned*, *action*接收客户端作为第2个参数。
- 修复了客户端死亡记录在重生时没有正确清除的问题
